# Football API — Pullable Leagues & Cups

Complete catalogue of every competition retrievable from the [API-Football](https://www.api-sports.io/) `/leagues` endpoint on the current plan, grouped by continent and then by country.

- **Total competitions:** 1235
- **Countries / regions:** 171
- **Source endpoint:** `GET https://v3.football.api-sports.io/leagues`
- **Type:** `League` = domestic league table · `Cup` = knockout/cup competition

> Use the numeric **ID** in the `league` param when querying `fixtures`, `standings`, `players`, etc. `Seasons` shows the earliest and latest season years available for that competition.
